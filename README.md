# Ruup Glass - B2B Wholesale & Trade Supply Web Platform

A high-performance, modern B2B wholesale web platform for Glassware, Storage Jars, Milk & Beverage Bottles, Luxury Decanters, and Caps/Closures. Built specifically for trade carton calculation, instant WhatsApp quotation generation, and Pan-India dispatch management.

---

## 🌟 Key Features

1. **Wholesale Product Catalog**:
   - Glass Jars & Food Storage Containers (Ghee, Honey, Pickles, Spices)
   - Milk & Beverage Glass Bottles (200ml, 500ml, 750ml)
   - Drinkware & Barware (Embossed Tiger & Lion Whisky Glasses, Plaza Tumblers)
   - Luxury Designer Decanters (Airplane Decanter, AK-47 Gun Decanter, Diamond Sets)
   - Lug & Plastic Caps (43mm, 63mm, 82mm, 101mm, Spice Shakers)
   - Bowls & Tableware Sets

2. **Carton & Bulk MOQ Calculator**:
   - Live calculation showing price per piece, carton quantity (e.g. 12 pcs, 24 pcs, 48 pcs per box), and total carton price.
   - Stepper to choose 1, 2, 5, 10+ cartons with live piece totals.

3. **1-Click WhatsApp Trade Quotation**:
   - Buyers can add cartons to their trade enquiry drawer.
   - Generates a neatly formatted B2B quote message with Item Codes, Alias names, Carton Counts, Total Units, and Estimated Billing sent directly to your WhatsApp number (**+91 7984086684**).

4. **Fast Multi-Field Search & Smart Filters**:
   - Live search by product name, item code (e.g., `23256`), alias (e.g., `RJ-1500`), or tags.
   - Filter by Category, Price Range, In-Stock status, and Sorting.

5. **In-Browser Catalog & Inventory Manager (Admin)**:
   - Click the ⚙️ Settings icon in the header to add new glassware items, update carton rates, change stock status, or remove products.
   - All changes persist in the browser via LocalStorage.

6. **Pan-India Transport & Godown Guide**:
   - Highlights ready container stock in Surat, Gujarat with transport hub transit times across India.


2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open your browser at `http://localhost:3000` (or the port shown in terminal).

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite 6
- **Styling**: TailwindCSS, PostCSS, Lucide Icons
- **Effects**: Canvas Confetti for trade quote feedback
- **State**: React Context with LocalStorage persistence
